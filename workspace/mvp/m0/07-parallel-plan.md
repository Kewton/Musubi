## 1. 結論：**並列度は2で足りる。3以上は待ち時間が増えるだけ**

理論上の波と、実際に走らせられる本数は違う。

| | 値 |
|---|---|
| クリティカルパス | **11段**（#2 → #3 → #5 → #6 → #8 → #9 → #10 → #15 → #16 → #17 → #18） |
| 🤖 が同時に着手できる最大 | **2〜3**（W0 のみ3、以降はほぼ2） |
| 🧑 タスク | **6件が最初から実行可能**。AI の進捗を一切ブロックしない |

**27件のうち 11件がクリティカルパス上にあり、その9件が 🤖 である。** つまり所要時間はほぼ
「1本の鎖を何段こなすか」で決まり、並列化で削れるのは残りの数件にすぎない。
ワーカーを4本立てても、3本は前段の完了を待って遊ぶ。

## 3. 実行レーン（これに沿って走らせる）

### レーン H — 🧑 本人（**いますぐ開始。AI を待たない**）

```
#19 商標クリアランスの調査発注  →  #20 ドメイン取得＋ゾーン委任
#21 WfP 不要の確定（wfp_enabled=false 固定）
#22 LINE Developers dev チャネル
#23 Google Cloud OAuth クライアント
#24 CommandAgent 接点・ピン対象の確定
```

**このレーンは AI の進捗を1ミリもブロックしない。** 逆に #19→#20 は外部の審査・伝播待ちが入るため、
**最初に着手しないと M4 の直前で詰まる**。#22・#23 も同じ理由で「枠だけ先に取る」タスクである。

### レーン A — 🤖 クリティカルパス（**1本目のワーカー。ここが遅れると全部遅れる**）

```
#2 → #3 → #5 → #6 → #8 → #9 → #10 → #15
```

途中で人の判断が要る箇所は無い。**このレーンを最優先で流す。**

### レーン B — 🤖 側道（**2本目のワーカー。レーンAの完了を待って拾う**）

```
#7  （いますぐ。依存なし）
#14 （#3 の後）
#13 （#5 の後）
#12 （#6 の後）
#11 （#9 の後）
#25 （#10 の後）
```

レーン B は待ち時間が空く。**空いたら次の波を先読みするのではなく、止めてよい。**
先に進めても W の壁で必ず待つ。

### 収束点 — 🧑🤖 人が必ず入る

```
#4  staging/production の apply      ← 本番アカウント②に初めて資源を作る
#16 deploy-production.yml            ← 承認ゲートの実動確認
#17 ロールバックの実演               ← 本番を1つ前へ戻す
#26 試験F（無償枠の清算）
#18 M0 受入試験
```

**この5件を無人のエージェントに渡さない。** production アカウントに触るか、
承認・実演・判定を伴う。`dispatch_defaults.auto_yes` を `false` にしてあるのはこのためである。

## 4. 同時に走らせてはいけない組み合わせ（ファイル衝突）

同じ波に入っていても、触るファイルが重なるものがある。

| 衝突 | 重なるファイル | 対処 |
|---|---|---|
| **#4 × #14** | `infra/terraform/**`（#14 は `account_id` を `sensitive = true` にするため変数定義に触る） | **直列にする。** #14 を先に入れてから #4 を流す |
| #10 × #25 | `infra/scripts/smoke.ts` | 依存関係で既に直列（#25 は #10 の後）。並べ替えない |
| #13 × #14 | `.github/workflows/`、`.commandmate/verify.yaml` | 波が別（W3 / W2）なので通常は衝突しない。**同時に動かさない** |
| #5 × #6/#8/#9 | 各パッケージの `wrangler.jsonc` | 依存関係で直列。#5 が全 `wrangler.jsonc` の形を決めてから各 Worker を作る |

衝突しない組み合わせ（安心して並列可）：**#2×#7**／**#6×#13**／**#8×#12**／**#10×#11**／**#15×#25**。

> `.commandmate/profiles/musubi.json` の `scope_companions.require` に
> 「`verify.yaml` を触ったら `ci.yml` も触る（逆も）」を入れてある。
> **検証ゲートの定義が2か所で食い違うと「ローカルは通るが CI で落ちる」が起きる。**
